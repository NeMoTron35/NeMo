# Inventory

Open `/positions`. Inspect the available demo position rows and use each row’s transaction-review control to open an inventory rebalance plan. The quote/base composition, liquidity and displayed returns are sample telemetry, not wallet-derived holdings or guaranteed yield.

## Inventory versus Portfolio

Inventory is the retained liquidity-position console. Portfolio at `/portfolio` is the separate read-only connected-wallet view. A row in Inventory does not mean the connected wallet owns that position.

## Position operations

Review lists operation steps and accounts. A demo preview does not withdraw, rebalance or migrate any position. For wallet safeguards, read [Wallet and transaction flow](/docs?article=wallet-flow).
