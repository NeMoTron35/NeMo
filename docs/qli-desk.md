# NEMOTRON3.5 Desk

## Desktop entry

`/` opens the API Desk: cosmic wallpaper, service health, observed checks, algorithm registry and Cryptography Workbench. `/overview` opens the retained liquidity operations overview with demo metrics, charts and operation previews. These are distinct views, not two sources of live portfolio data.

## Cryptography Workbench

Select ML-DSA-65, SLH-DSA-SHA2-128s or ML-KEM-768. Signature modes generate a local test key, sign the message and verify. ML-KEM generates keys, encapsulates and decapsulates locally. The tamper control changes the verified message or ciphertext. Reset clears displayed results. Public test material can be inspected and copied; secret keys are not included.

## Observed service checks

Health performs real ML-DSA and ML-KEM tests. The history is volatile worker memory, not a durable monitoring service. Empty chart slots mean no measurement, not downtime or uptime. No 24-hour or 7-day uptime guarantee is calculated.

## Operations overview

Metrics and pool telemetry in the retained overview are demonstrations. Chart ranges and strategy previews work locally; they do not turn demo balances into executable positions.
