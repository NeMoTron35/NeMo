# Welcome to Quantum QLi

Quantum QLi brings liquidity operations, token launch planning, identity proofs and public cryptography tools into one classic desktop workspace. The Dock, application source list and global menus open the same retained tools. QLi Console reports public session status and reviewed-plan titles, not private keys or raw RPC addresses.

## What works today

- Browser-local ML-DSA-65 and SLH-DSA-SHA2-128s signature tests, plus ML-KEM-768 roundtrips.
- A seven-stage Meteora DBC launch draft and review, with DAMM v2 migration planning.
- Wallet-derived reference identities, local WOTS registration, possession proofs and proof inspection.
- Simulated liquidity operations, market demonstrations and session strategies.
- Read-only wallet balances and transaction views where RPC access is available.
- Public signature verification and key encapsulation endpoints.

## What this is not

This is not an autonomous trading service, audited custody system or deployed quantum vault. Operational demo rows are not live positions. A signed anchor is not a submitted or confirmed anchor. Ordinary Solana accounts remain authorized by ed25519.
